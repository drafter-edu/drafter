# Your Project

You have built the guided projects; now you are building your own thing.
This section is the road from "I have an idea" to "here is my link",
one step at a time. Start here even if your course handed you a spec:
the steps are the same, you just skip choosing the topic.

| Step | You will | Done when |
| ---- | -------- | --------- |
| 1. [Choose a manageable idea](choose-an-idea.md) | Pick a project shape that fits the time you have | You can say what it does in one sentence |
| 2. [Sketch the pages](sketch-the-pages.md) | Draw every page and how they connect | Paper sketches, with arrows |
| 3. [Decide what to remember](plan-your-data.md) | Design your `State` from the sketches | A written dataclass |
| 4. [Build one working path](build-one-path.md) | Get one thin slice working end to end | You can click from start to one result |
| 5. [Add features one at a time](add-features.md) | Grow the app without breaking it | Each feature works before the next begins |
| 6. [Test as you go](test-as-you-go.md) | Keep what works working | Tests pass on every run |
| 7. [Improve the design](improve-the-design.md) | Make it pleasant and usable | Someone else can use it unaided |
| 8. [Deploy and submit](deploy/index.md) | Put it on the web | Your link works on another device |

Along the way, [Add to Your App](../add/index.md) is your recipe book:
whenever the next feature is "let them upload a picture" or "show a
table", there is a page for exactly that.

## Want inspiration?
