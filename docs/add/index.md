# Add to Your App

You are building something and want to add one specific thing. Find it
below; every page opens with a working example you can adapt.

## Pages and navigation

- [Add and connect pages](pages.md): more pages, buttons, links, going back.
- [Show different content](show-different-content.md): one page that
  changes with the situation.
- [Add live behavior](live-behavior.md): react to typing without a page
  change.

## Information

- [Ask the user for information](ask-for-information.md): text boxes,
  checkboxes, dropdowns.
- [Remember a score or choice](remember-things.md): keep values between
  clicks and pages.
- [Show a collection of items](show-a-collection.md): lists and tables
  from your data.
- [Use pictures](pictures.md): show, upload, and edit images.
- [Upload and download files](files.md): move files in and out.

## Appearance

- [Change the appearance](change-appearance/index.md): themes, styling
  helpers, and CSS, in order of effort.
- [Embed HTML](html.md): raw HTML, when components are not enough.
- [Make things happen over time](timers.md): countdowns, ticks, clocks.

## Quality

- [Test a feature](test-a-feature.md): focused tests for your routes.
- [Freeze finished pages](freeze-pages.md): auto-generated regression
  tests.

## How these pages work

Each task page follows the same shape: the smallest working example
first, then variations, then common problems. At the end of every page,
four links:

- **Understand it**: the concept behind the recipe.
- **See another example**: the same idea in a different app.
- **Look it up**: exact parameters in the reference.
- **Fix a problem**: the errors this feature usually produces.
