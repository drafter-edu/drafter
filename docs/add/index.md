# Add to Your App

You are building an app and want to add one specific feature. Find the
matching page below. Every page opens with a working example you can
adapt.

## Pages and navigation

- [Add and connect pages](pages.md): add more pages, connect them with
  buttons and links, and offer a way back.
- [Show different content](show-different-content.md): build one page
  that changes with the situation.
- [Add live behavior](live-behavior.md): react to typing without a full
  page change.

## Information

- [Ask the user for information](ask-for-information.md): collect input
  with text boxes, checkboxes, and dropdowns.
- [Remember a score or choice](remember-things.md): keep values between
  clicks and across pages.
- [Show a collection of items](show-a-collection.md): display lists and
  tables built from your data.
- [Use pictures](pictures.md): show, upload, and edit images.
- [Upload and download files](files.md): move files into and out of
  your app.

## Appearance

- [Change the appearance](change-appearance/index.md): choose among
  themes, styling helpers, and CSS, ordered by effort.
- [Embed HTML](html.md): use raw HTML when components are not enough.
- [Make things happen over time](timers.md): add countdowns, ticks, and
  clocks.

## Quality

- [Test a feature](test-a-feature.md): write focused tests for your
  routes.
- [Freeze finished pages](freeze-pages.md): generate regression tests
  automatically from pages you approve.

## How these pages work

Each task page follows the same shape: the smallest working example
comes first, then variations, then common problems. Every page ends
with the same four links:

- **Understand it** leads to the concept behind the recipe.
- **See another example** shows the same idea in a different app.
- **Look it up** gives the exact parameters in the reference.
- **Fix a problem** covers the errors this feature usually produces.
