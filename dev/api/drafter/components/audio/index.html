    audio

    Web Audio components for playing, analyzing, and recording sound.

    Provides five components built on the browser's Web Audio API:

    • :class:Tone: play a single pitch (a note name like "C4" or a frequency in Hz) with a chosen waveform.
    • :class:Melody: play a sequence of notes at a tempo; a melody is just a Python list, so students can compose music with list operations.
    • :class:Sound: play an audio file through an optional chain of effects (echo, reverb, muffle, sharpen, distortion) with volume/pan/speed control.
    • :class:Microphone: monitor live microphone input, firing events when the room gets loud or quiet and providing an :class:AudioLevel snapshot on form submission.
    • :class:AudioRecorder: record microphone audio and submit it as a :class:Recording that can be played back with :class:Sound.

    The Python side only describes the components: each renders as a custom element (<drafter-tone>, <drafter-melody>, <drafter-sound>, <drafter-microphone>, <drafter-audio-recorder>) whose behavior is implemented in js/src/components/. A single shared AudioContext lives in js/src/components/audioBroker.ts; because browsers require a user gesture before sound can play, components rendered before any interaction show a small "Enable sound" prompt (the audio analog of the geolocation permission prompt).

    Like :class:~drafter.components.geolocation.CurrentLocation, the :class:Microphone and :class:AudioRecorder components keep a hidden form field (named after the component) updated with JSON-encoded data; converters registered below turn those payloads into :class:AudioLevel and :class:Recording values when a matching route parameter is annotated with them. Failures become status values rather than exceptions, so routes can inspect problems without try/except.

    MicrophoneStatus = Literal['unavailable', 'prompt', 'pending', 'granted', 'denied', 'error'] module-attribute

    The permission/availability states an AudioLevel's status field can report, mirroring the microphone permission workflow.

    NoteValue = str | tuple[str, int | float] module-attribute

    One item in a Melody's note list: a note name like "C4" (or "rest"), played for one beat, or a (note, beats) pair like ("C4", 2).

    REST = 'rest' module-attribute

    A note that plays silence for its beats in a Melody.

    RecordingStatus = Literal['unavailable', 'prompt', 'recording', 'granted', 'denied', 'error'] module-attribute

    The permission/recording states a Recording's status field can report.

    VISUALIZATIONS = ('meter', 'waveform', 'bars') module-attribute

    The live visualization styles a Microphone can draw; Sound supports the "waveform" and "bars" subset.

    WAVEFORMS = ('sine', 'square', 'triangle', 'sawtooth') module-attribute

    The oscillator waveform names accepted by Tone and Melody.

    AudioEffect() dataclass

    Base class for audio effects that can be chained onto sound.

    Effects are plain values, not components: pass a list of them as the effects parameter of :class:Sound, :class:Tone, or :class:Melody, and they are applied in order.

    to_config()

    Serialize this effect to the JSON configuration the JS side reads.

    Melody(notes, tempo=120, waveform='sine', volume=0.8, auto_play=False, controls=False, show=True, effects=None, on_note=None, on_finish=None, **extra_settings) dataclass

    Bases: Component

    Plays a sequence of notes at a tempo using the Web Audio API.

    A melody is just a list: each item is a note name like "C4" (played for one beat), a (note, beats) pair like ("C4", 2), or "rest" for silence. Notes are scheduled with sample-accurate Web Audio timing, so melodies stay in rhythm.

    Note

    An on_note handler that returns a full :class:~drafter.Page re-renders the whole page, which stops and resets this melody after its very first note. To react to notes while the melody keeps playing, return an Update (change state only) or a Fragment targeting another element; save full pages for on_finish.

    Microphone(name, threshold=0.5, cooldown=1000, rate=0, show=True, visualize='meter', on_loud=None, on_quiet=None, on_level=None, on_denied=None, on_error=None, **extra_settings) dataclass

    Bases: Component

    Monitors live microphone input and reports how loud the room is.

    This component follows the same permission workflow as :class:~drafter.components.geolocation.CurrentLocation: it shows an "Enable microphone" prompt, and once permission is granted it displays a live level meter. It keeps a hidden form field (named name) updated with the latest :class:AudioLevel snapshot, so a route parameter with the same name annotated as :class:AudioLevel receives the converted value on any form submission.

    The on_loud event is the easiest way to react to sound: it fires when the volume crosses threshold (a clap, a shout), and then not again until cooldown milliseconds have passed. Volume is measured as the peak signal level, so brief sounds like claps register at their full loudness.

    Note

    An on_loud/on_quiet/on_level handler that returns a full :class:~drafter.Page re-renders the whole page, briefly resetting this component (it re-enables itself, but the meter and peak_volume restart). For frequent events, prefer returning an Update (change state only) or a Fragment targeting another element.

    Attributes:

    Name Type Description
    name str

    The form field name that will contain the AudioLevel data.
    threshold float

    The loudness (0.0 to 1.0) that counts as "loud". Defaults to 0.5.
    cooldown int

    Minimum milliseconds between on_loud events. Defaults to 1000.
    rate int

    Milliseconds between on_level events, or 0 to never fire them. Defaults to 0.
    show bool

    Whether to display the permission UI and meter. Defaults to True.
    visualize str

    The live display once granted: "meter", "waveform", or "bars". Defaults to "meter".
    on_loud UrlOrFunction | None

    Function or URL to call when the volume rises past threshold.
    on_quiet UrlOrFunction | None

    Function or URL to call when the volume falls back below threshold.
    on_level UrlOrFunction | None

    Function or URL to call every rate milliseconds with the current volume.
    on_denied UrlOrFunction | None

    Function or URL to call when microphone permission is denied.
    on_error UrlOrFunction | None

    Function or URL to call when the microphone fails.

    Tone(pitch, duration=500, waveform='sine', volume=0.8, attack=10, release=50, auto_play=False, show=True, effects=None, on_start=None, on_finish=None, on_error=None, **extra_settings) dataclass

    Plays a single pitch using the browser's Web Audio API.

    The pitch can be a note name like "C4" or "F#3", or a raw frequency in Hz like 440. By default the component renders a small play button; with auto_play=True it plays as soon as the page loads (browsers require at least one interaction with the page first, so a tone on the very first page shows an "Enable sound" prompt instead).

    Attributes:

    Name Type Description
    pitch str | int | float
