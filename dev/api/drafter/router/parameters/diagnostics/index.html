    diagnostics

    Structured diagnostics for the parameter pipeline.

    The merge and bind stages report everything that goes wrong (or is merely suspicious) as RouteDiagnostic values instead of raising immediately. The router then partitions them: warnings are logged, and errors are raised together as a single ParameterBindingError so the debug panel can explain every problem at once.

    DiagCode = Literal['missing_required_parameter', 'unused_request_parameter', 'name_mismatch_suggestion', 'conversion_failed', 'payload_collision'] module-attribute

    Stable machine-readable codes identifying each kind of diagnostic.

    Severity = Literal['info', 'warning', 'error'] module-attribute

    How serious a diagnostic is; only "error" aborts the request.

    ParameterBindingError(diagnostics)

    Bases: ValueError

    Raised when a route's parameters cannot be bound or converted.

    Carries the structured diagnostics so the debug panel can explain what failed, where the value came from, and how to fix it.

    RouteDiagnostic(severity, code, route_name, message, parameter='', source='', hint='', related=()) dataclass

    One problem (or observation) found while binding route parameters.

    Attributes:

    Name Type Description
    severity Severity

    How serious the diagnostic is (info, warning, or error).
    code DiagCode

    Stable machine-readable code identifying the kind of problem.
    route_name str

    Name of the route function being bound.
    message str

    Student-facing description of what went wrong.
    parameter str

    Name of the parameter or payload key involved, if any.
    source str

    Payload source the value came from (e.g. form_field), if any.
    hint str

    Student-facing suggestion for how to fix the problem.
    related tuple[str, ...]

    Names of other parameters or payload keys involved.

    format_diagnostic(diagnostic)

    One-line student-facing rendering: the message plus its fix hint.

    partition_diagnostics(diagnostics)

    Split diagnostics into (errors, non-errors).
